# 乘法计算练习题生成器（math-worksheet）

生成 **A4 纵向、直接打印** 的乘法计算练习题 PDF。支持三位数×三位数、四位数×四位数、
五位数×五位数（可多选混合），带日期与姓名/班级/用时/得分栏，同一天内题目自动去重。

- **支持一次生成多天**：按 **日期区间** 出卷，可按 **星期几** 过滤（如只要周一/三/五），
  多天结果可**合并为一个 PDF**，也可**每天一份 PDF 打包成 ZIP**
- 纯本地运行，不联网、不上传题目
- 依赖仅 `reportlab`（本机已安装）
- 提供 **本地网页 UI**（推荐，点选即生成）与 **命令行** 两种用法

## 一、快速开始

### 方式 A：图形界面（推荐）

**双击项目根目录的 `启动UI.bat`**（`start_ui.bat` 为同一启动器，任选其一）。

启动后会弹出一个命令行窗口，显示：

```
  Starting local UI ...
      http://127.0.0.1:8765/
```

浏览器通常会**自动打开** <http://127.0.0.1:8765/>；
**若没有自动打开，请手动在浏览器地址栏输入 `http://127.0.0.1:8765/`**（这一条最常见）。

在页面上勾选参数，点「生成并下载 PDF」即可。**关闭该命令行窗口即退出程序。**

如果窗口一闪而过、或提示错误：查看同目录下的 **`ui_launch.log`**，
里面记录了启动时间、实际使用的 Python 解释器、以及退出码，可直接定位问题。
启动器会自动在以下位置寻找 **可用（含 reportlab）** 的 Python：

1. PATH 中的 `python`
2. `%LOCALAPPDATA%\Programs\OfficeAce\tools\python\python.exe`
3. `C:\Python313\python.exe`、`C:\Python312\python.exe`、`C:\Python311\python.exe`

也可以直接在命令行运行（需要 `python` 在 PATH 中）：

```bash
python app_web.py
```

### 方式 B：命令行

```bash
# 单日：四位数 × 四位数，6 题/页，1 页
python generate.py --digits 4 --per-page 6 --pages 1

# 三种位数混合，3 列排版，每天 2 页
python generate.py --digits 3,4,5 --per-page 15 --columns 3 --pages 2

# 指定日期、标题，附用时栏，固定随机种子（可复现）
python generate.py --digits 4 --date 2026-10-08 --title "大数乘法练习" --seed 123

# 日期区间：10-09 ~ 10-31 的每周一/三/五，每天 1 页，合并成一个 PDF
python generate.py --digits 4 --date 2026-10-09 --end-date 2026-10-31 --weekdays 1,3,5

# 同上，但每天导出独立 PDF 并打包为 ZIP
python generate.py --date 2026-10-09 --end-date 2026-10-31 --weekdays mon,wed,fri --zip
```

## 二、命令行参数

| 参数 | 简写 | 默认 | 说明 |
|---|---|---|---|
| `--digits` | `-d` | `4` | 乘数位数组合，逗号分隔。`4`=四位数×四位数；`3,4,5`=三种混合 |
| `--per-page` | `-n` | `6` | 每页题目数量 |
| `--pages` | `-p` | `1` | **每天**生成页数（多天时逐日套用） |
| `--columns` | `-c` | `2` | 每页列数（行数按题量自动推算） |
| `--title` | | `乘法计算练习` | 卷面标题 |
| `--date` | | 今天 | 起始日期（单日模式即该日期），格式 `yyyy-MM-dd` |
| `--end-date` | | 无 | 结束日期；填了即为**日期区间模式**，逐日出卷（含首尾两天） |
| `--weekdays` | | 不限定 | 星期过滤，支持 `mon,wed,fri` / `周一,周三` / `1,3,5`（1=周一）。留空表示每天都出 |
| `--no-weekday` | | 关闭 | 页眉日期后**不显示**星期（默认显示，如 `2026-10-09（周五）`） |
| `--zip` | | 关闭 | 多天时**每天一个 PDF** 并打包为 ZIP（默认合并为一个 PDF） |
| `--font-size` | | `14` | 题面字号（pt），过长算式会自动缩排 |
| `--no-name` | | 关闭 | 不显示「姓名」栏 |
| `--no-class` | | 关闭 | 不显示「班级」栏 |
| `--no-time` | | 关闭 | 不显示「用时」栏（默认显示） |
| `--no-score` | | 关闭 | 不显示「得分」栏（默认显示） |
| `--no-dedup` | | 关闭 | 关闭题目去重（默认开启） |
| `--dedup-scope` | `page`\|`sheet` | `page` | 去重范围：`page`=**同一天内**不重复（跨天、跨页可重复）；`sheet`=整份文件内不重复 |
| `--no-strict` | | 关闭 | 关闭严格数字规则（默认开启：不含 0/1、各位不重复、相邻不连号） |
| `--seed` | | 无 | 随机种子，固定后题目可复现 |
| `-o` / `--output` | | 自动 | 输出路径；不填时按 `examples/{标题}_{位数}[_区间信息].pdf|.zip` 自动命名 |

## 三、多日期出卷

一次生成多天时，**每一天从新的一页开始**，页眉日期逐日变化（可选带星期），
页码在整份文件中**连续编号**（如 `第 3 / 10 页`）。

| 需求 | 做法 |
|---|---|
| 生成某个星期一到星期五 | `--date 2026-10-12 --end-date 2026-10-16` |
| 只要区间内的周一/三/五 | 再加 `--weekdays 1,3,5` |
| 生成整个 10 月（每天都出） | `--date 2026-10-01 --end-date 2026-10-31` |
| 每天 2 页 | `--pages 2` |
| 每天一份独立 PDF | 加 `--zip`（输出 ZIP 包，内含按日期命名的 PDF） |
| 页眉不要星期 | 加 `--no-weekday` |

- 去重范围默认 **`page`：只保证「同一天内」不重复**，跨天、跨页允许出现相同题目；
  若要整份文件内都不重复，加 `--dedup-scope sheet`。
- UI 中对应「日期模式：单日 / 区间」，选区间后出现结束日期与 7 个星期勾选框、
  「输出形式：合并为一个 PDF / 每天一个 PDF（ZIP）」，以及
  「去重：同一天内不重复（默认）/ 整份文件不重复 / 不去重」。

## 四、版面说明

- 纸张：A4 纵向（210 × 297 mm，595 × 842 pt），页边距约 16 mm
- 页眉：标题居中；左侧姓名/班级/用时/得分（可关），右上角日期（可含星期）；下方分隔线
- 题目区：按「列数 × 行数」网格排布，题面形如 `1234 × 5678 =`，右侧留白供竖式计算
- 页脚：`第 x / y 页`
- 若某题过宽超出格宽，会自动收缩该题字号（最低 9pt），不会越界

### 题量建议

| 乘数位数 | 建议每页题数 | 说明 |
|---|---|---|
| 三位数 × 三位数 | 12–16 | 结果最多 6 位 |
| 四位数 × 四位数 | 6–12 | 结果最多 8 位，竖式占高 |
| 五位数 × 五位数 | 8–12 | 结果最多 10 位，建议适当减少 |

## 五、出题规则

1. 取数区间：`d` 位数取值范围为 `10^(d-1) ~ 10^d - 1`（如三位数 = 100–999）
2. 去重：默认开启，范围 **`page` = 只保证同一天内不重复**（跨天、跨页可重复）；
   `--dedup-scope sheet` 可改为整份文件内不重复；`a×b` 与 `b×a` 视为同一题
3. 混合位数：多选时按轮转分配，使各组合在整卷中数量均衡
4. 复现：`--seed` 固定后，同参数生成完全相同的题目
5. **严格数字规则（默认开启）**：每个乘数均满足 ——
   - 不含数字 **0 和 1**
   - 各位数字**互不相同**（无重复数字）
   - **相邻两位不能连续**（相差 1 的连号，如 23 / 34 / 87 均不允许）

   可用数字池为 `{2,3,4,5,6,7,8,9}`；关闭方式：CLI 加 `--no-strict`，或取消 UI 中「严格数字规则」勾选。
6. 无答案页：按需求不输出答案

> ⚠️ 严格规则下可用组合有限：一次性生成**多天且题量很大**时，可能出现
> 「可用题目组合不足」的报错。此时请减少天数/每页题数，或关闭严格规则。

## 八、常见问题

**Q：双击 `启动UI.bat` 没反应 / 窗口一闪而过？**
A：新版启动器（纯 ASCII 内容，避免中文编码导致的批处理解析失败）会自动查找可用的 Python。
请查看同目录 `ui_launch.log`：

- 没有该文件 → 批处理根本没被执行，请确认是在**文件资源管理器**中双击（不是在聊天窗口里点文件名）。
- 日志末尾出现 `[ERROR] No usable Python found` → 未找到带 reportlab 的 Python，执行
  `pip install reportlab`，或把 Python 加入 PATH。
- 日志出现 `app_web exited with <码>` → 把退出码连同该日志反馈，便于定位。

**Q：命令行窗口开着，但浏览器没自动打开？**
A：服务其实已经在运行，手动访问 <http://127.0.0.1:8765/> 即可。

**Q：端口 8765 被占用？**
A：程序会自动顺延到 8784 内的可用端口，控制台会打印实际地址。

**Q：想固定每次生成同一份试卷？**
A：设置相同的 `--seed`（UI 中填「随机种子」），并保持其他参数一致。

**Q：多天的卷子里题目会重复吗？**
A：默认不会 —— 去重范围 `page` 只保证**同一天内**不重复，跨天、跨页允许出现相同题目。
若希望整份文件内都不重复，把去重范围改成 `sheet`（CLI：`--dedup-scope sheet`）。

**Q：提示「可用题目组合不足」？**
A：四位数×四位数在严格数字规则下的组合数量有限，去重范围越大越容易耗尽。
可减少每页题数、关闭「严格数字规则」，或把去重范围保持在默认的 `page` 后重试。
